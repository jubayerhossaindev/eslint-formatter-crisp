# Support

- **Usage questions:** open a GitHub Discussion when enabled for the repository, or file an issue with a minimal reproduction.
- **Bugs:** use the bug report template and include OS, architecture, Node.js, ESLint, and package versions.
- **Security issues:** follow `SECURITY.md`; do not disclose an unpatched vulnerability publicly.
- **Documentation:** see the Fumadocs site linked from the root README.

This repository is maintained on a best-effort basis. Please include the output of the relevant package tests when reporting regressions.
