# API Overview

## Exports

- Default export: The formatter function
- Named exports: `format`, `detectColorLevel`, `detectLinks`, `nativeLoaded`

## Subpaths

- `eslint-formatter-crisp` - Terminal formatter
- `eslint-formatter-crisp/json` - JSON output
- `eslint-formatter-crisp/sarif` - SARIF 2.1.0 output
