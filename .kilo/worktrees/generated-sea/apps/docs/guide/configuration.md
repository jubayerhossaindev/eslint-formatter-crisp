# Configuration

Crisp respects standard ESLint configuration. Control output with environment variables:

- `FORCE_COLOR` - Force color output
- `NO_COLOR` - Disable color output
- `CRISP_ASCII` - Use ASCII characters
- `CRISP_FULL_LINES` - Show full lines without truncation
- `CRISP_MAX_MESSAGES` - Limit number of messages shown
- `CRISP_SUGGESTIONS` - Show fix suggestions
